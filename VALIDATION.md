# Reproduction and qualification

The collection is generated from the frozen complete engine source;
`scripts/export.py --check` verifies every generated byte, patch SHA256, source
commit/parent and all 32 intermediate Git trees. A fresh temporary index starts
at official upstream `94602c9`; `git apply --cached --check` and actual
application are performed for each active entry. The final tree is
`0dacab8ac525e59aa02875bfd83c1157637a4bc9`. The verifier does not modify the
source working tree or index, and it permits selector-owned patch files outside
the active series while requiring exactly one active Governor integration.

The ordered first 30 entries preserve the existing common/Qwen/GLM source
history. Entry 31 is the common pre-header HTTP error propagation fix. Entry 32
is the exact external Governor hook, retaining component ownership and patch
bytes. Runtime Governor requires independently pinned component commit
`5c34e89673b21a4c87fea6967a0afced51161b8f`, version 0.2.0, Rust ABI 4.

## Limits

- CPU tests do not qualify the final runtime image, GPU models or throughput.
  The fixed C4 test environment is not final cu130 dependency acceptance.
- Governor enablement remains TP1/PP1/DP1, non-overlap and null disaggregation.
  Inclusion of hooks does not establish Governor support on GLM/Kimi/DeepSeek.
- FlashInfer is external 0.6.18 code. Its manifest pins cu130 base digest
  `06e4f2ed21afde4ff513cda65070124e727ba23ccaeff7712b8c40e1097d611f` and exact
  before/after file hashes. Applying the Git patch only adds this build overlay;
  the image installer must separately apply and validate it in FlashInfer.
- Host async ACK stays opt-in with its original topology/storage guards.
- The Kimi delayed-abort original-owner guard is not yet integrated; the current
  delayed task checks RID existence and has a known RID-reuse window. Kimi DCP8
  logical 512/physical 64 continuation is not proven by GLM page 64 regressions.
- DeepSeek and legacy five-CVM migration increments were not incorporated.
  DS35b7 protocol 4/7 is not acceptance; model guards and the distinct dense-indexer
  workspace issue remain. v0.5.19/XGrammar variants require semantic review.

Historical failed attempts, PRs and all five archive tags remain retained.
